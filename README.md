# Target Hisobot — demo

Mijozlarga ko'rsatish uchun reklama + CRM + sotuv hisoboti namunasi (Apple do'koni misolida).
Barcha raqamlar `config.js` asosida avtomatik yaratiladi — haqiqiy ma'lumot emas.

**Kirish:** `demo` / `demo2026` (Sozlamalar bo'limidan almashtiriladi).
Taqdimot login'siz ham ochiladi: `/#taqdimot`.

## Yangi mijoz uchun
1. Repo nusxasini oling.
2. `config.js` da nom, rang, maqsad lid narxi, byudjet, kampaniyalar, reklamalar, sotuvchilar va paket narxini o'zgartiring.
3. GitHub Pages (Settings → Pages → main / root) yoki Vercel'ga ulang.

## Bo'limlar
Umumiy (spidometr, KPI, grafik, voronka) · Kampaniyalar · Lidlar · Sotuvchilar · Sozlamalar (login/parol, foydalanuvchilar, ko'rsatkichlar, o'z formulasi, rang) · Tizim haqida (taqdimot).

> Demo'da login va sozlamalar brauzer xotirasida saqlanadi (har qurilmada alohida). Haqiqiy mijoz tizimida server tomonda tekshiriladi.
